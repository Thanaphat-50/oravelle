# แชท: กล้อง ไฟล์ ลิงก์ เสียง อีโมจิ พื้นหลัง และการโทร

## สื่อในแชท (ใช้ได้ทั้งแชทส่วนตัว ร้านค้า และกลุ่ม)
- ปุ่ม ⊕ → ถ่ายรูป (ดูตัวอย่าง ถ่ายใหม่ ใส่คำบรรยาย) / เลือกรูป / ส่งไฟล์ / แชร์ลิงก์
- ไฟล์: PDF, TXT, DOCX, XLSX, PPTX ไม่เกิน 10 MB — เซิร์ฟเวอร์ตรวจชนิดจากเนื้อไฟล์จริง ไม่รับไฟล์ที่รันได้/มีมาโคร
- ข้อความเสียง: ปุ่มไมค์ (ช่องพิมพ์ว่าง) อัดได้ 3 นาที ฟังก่อนส่ง ลบแล้วอัดใหม่ได้ — เซิร์ฟเวอร์อ่านความยาวจากไฟล์เอง
- ลิงก์: แตะได้เฉพาะ http/https และแสดงโดเมน + URL ก่อนเปิดเสมอ (ยังไม่มีภาพตัวอย่างเว็บ)
- อีโมจิ: ปุ่มในช่องพิมพ์ สลับกับแป้นพิมพ์ แทรกที่ตำแหน่งเคอร์เซอร์ (แยกจาก Reaction)
- ไฟล์/เสียงเก็บในพื้นที่ส่วนตัว เปิดผ่านลิงก์ชั่วคราว 10 นาทีที่ผูกกับผู้ดูและตรวจสิทธิ์ห้องทุกครั้ง
  (สมาชิกใหม่/กลับเข้ากลุ่มรอบใหม่เปิดไฟล์รอบเก่าไม่ได้ / ออกจากกลุ่มแล้วเปิดไม่ได้ทันที)
- ลิงก์ที่ออกไปแล้วยังใช้ได้ไม่เกิน 10 นาทีหลังออกจากระบบบนเครื่องนั้น (ถ้ายังเป็นสมาชิกห้อง)
  ไฟล์ที่ผู้ใช้ดาวน์โหลดลงเครื่องไปแล้ว แอปเรียกคืนไม่ได้

## พื้นหลังแชท
- เมนู ⋮ ในห้อง → พื้นหลังแชท: สีพื้น / พื้นหลังสำเร็จรูป / รูปจากเครื่อง + ความจาง
- เก็บในเครื่องนี้ แยกตามบัญชีและห้อง ไม่ซิงก์ข้ามเครื่อง สมาชิกคนอื่นไม่เห็น รูปไม่ถูกอัปโหลด

## โทรเสียง / วิดีโอคอล 1 ต่อ 1 (LiveKit Cloud)
### ตั้งค่า (ทำใน Laravel Cloud เท่านั้น)
```
LIVEKIT_URL=wss://ชื่อโปรเจกต์.livekit.cloud   (ใส่ https:// ก็ได้)
LIVEKIT_API_KEY=...
LIVEKIT_API_SECRET=...
```
ยังไม่ใส่ → ระบบโทรปิด (API ตอบ 503 / แอปไม่แสดงปุ่มโทร)

### ทำงานอย่างไร
- Laravel เก็บแค่สถานะสาย + ตรวจสิทธิ์ + ออก token อายุ 5 นาที (เข้าห้องของสายนั้นห้องเดียว)
  เสียงและวิดีโอวิ่งผ่าน LiveKit (มี TURN ใช้ข้ามเครือข่ายได้) ไม่ผ่าน Laravel ไม่มีการบันทึก
- สถานะ: ringing → accepted → ended / declined / cancelled / missed (45 วินาที) / busy / failed
- คนละ 1 สาย: ปลายสายมีสายอยู่ → "ปลายสายไม่ว่าง" / รับพร้อมกันหลายเครื่อง → เครื่องเดียวได้
- สิทธิ์เดียวกับส่งข้อความ (บล็อก / อยู่กลุ่มเดียวกัน / ลูกค้า-ร้าน) ตรวจตอนเริ่ม รับ และทุก 15 วินาทีระหว่างสาย
- บล็อก / ออกจากกลุ่ม / เพิกถอนเซสชันที่ใช้โทร → สายถูกตัด และเซิร์ฟเวอร์ลบห้อง LiveKit
- แจ้งเตือนสายเข้าไม่มีเนื้อหาแชท ใช้การตั้งค่าแจ้งเตือน "ข้อความใหม่" / การปิดเสียงแชทกลุ่มไม่เกี่ยวกับสายโทร
- แจ้งเตือนสายเข้าถูกแทนที่ด้วย "รับสายที่อุปกรณ์อื่นแล้ว" / "สายที่ไม่ได้รับ" → เครื่องอื่นหยุดเรียก

### ข้อจำกัดตอนนี้
- สายเข้าตอนแอปอยู่เบื้องหลัง/ปิดอยู่ = แจ้งเตือนแบบเด้ง แตะแล้วเปิดหน้ารับสาย
  ยังไม่ใช่หน้าจอสายเข้าเต็มจอ/เสียงเรียกเข้าวน (ต้องเพิ่ม native + แจ้ง Play Console เรื่อง full-screen intent)
- ในแอปไม่มีเสียงเรียกเข้า (มีเสียงจากแจ้งเตือน)
- ยังไม่มีโทรกลุ่ม (ไม่แสดงปุ่มในแชทกลุ่ม)
- แอปมีแค่ Android

### เช็กลิสต์ทดสอบบนมือถือจริง (บัญชีทดสอบ 2 บัญชี มือถือ 2 เครื่อง)
1. เครื่อง A Wi-Fi / เครื่อง B เน็ตมือถือ (ต่างเครือข่าย): โทรเสียง → รับ → ได้ยินทั้งสองทาง → วางสาย
2. วิดีโอคอล: เห็นภาพทั้งสองฝั่ง ปิด/เปิดกล้อง สลับกล้อง ปิดไมค์ ลำโพง
3. ปฏิเสธ / ผู้โทรยกเลิก / ไม่รับ 45 วินาที / ปลายสายไม่ว่าง
4. B ล็อกอิน 2 เครื่อง: รับที่เครื่องหนึ่ง → อีกเครื่องหยุดเรียก
5. ปิดเน็ตระหว่างคุย 10 วินาทีแล้วเปิด (ต่อใหม่) / ปิดเน็ตนานกว่า 60 วินาที (สายหลุด)
6. B อยู่เบื้องหลัง / B ปัดปิดแอป → แจ้งเตือนสายเข้า → แตะ → รับสายได้
7. บล็อกระหว่างคุย / เพิกถอนเครื่องจากหน้า "อุปกรณ์ที่เข้าสู่ระบบ" ระหว่างคุย → สายถูกตัด
