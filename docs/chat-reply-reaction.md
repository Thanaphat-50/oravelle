# แชท: ตอบกลับ / Reaction / สถานะอ่าน (แชทส่วนตัว ร้านค้า และกลุ่ม)

## หน้าจอ (แอป)
- โค้ดร่วม: `lib/widgets/chat_widgets.dart` (ชิ้นส่วน UI) + `lib/widgets/chat_room_logic.dart` (ตรรกะห้องแชท)
  ใช้ทั้ง `chat_room_page.dart` (ส่วนตัว/ร้านค้า) และ `group_chat_page.dart` (กลุ่ม)
- หัวห้อง: รูป ชื่อ จำนวนสมาชิก (กลุ่ม) — ไม่มีสถานะ "ออนไลน์"
- ข้อความต่อเนื่องจากคนเดียวกัน (วันเดียวกัน ห่างไม่เกิน 5 นาที) รวมเป็นชุด: ชื่อ/รูปแสดงครั้งเดียว เวลาใต้ข้อความสุดท้าย
- ตัวแบ่ง วันนี้ / เมื่อวาน / วันที่ และเส้น "ข้อความที่ยังไม่ได้อ่าน" (ตามตำแหน่งอ่านตอนเปิดห้อง ไม่ขยับระหว่างอยู่ในห้อง)
- เลื่อนอ่านข้างบนแล้วมีข้อความใหม่ → ไม่เลื่อนจอเอง แสดงปุ่ม "↓ ข้อความใหม่" / โหลดข้อความเก่าแล้วตำแหน่งเดิมไม่กระโดด
- ช่องพิมพ์: ขยายได้ 5 บรรทัด แนบรูป (ดูตัวอย่าง/เอาออก/พิมพ์คำบรรยาย) ร่างข้อความจำไว้ต่อห้องจนปิดแอป (ไม่บันทึกลงเครื่อง)
- ส่งไม่สำเร็จ → ข้อความและรูปยังอยู่ ส่งอีกครั้งด้วย client_id เดิม (ไม่ซ้ำ) / แก้ไข / คัดลอก / ลบ

## ตอบกลับ (Reply)
- ปัดข้อความไปทางขวา หรือกดค้าง → "ตอบกลับ" → แถบเหนือช่องพิมพ์ (กดกากบาทเพื่อยกเลิก)
- แตะข้อความอ้างอิง → เลื่อนไปต้นทาง (ยังไม่ได้โหลด → โหลดย้อนหลังทีละหน้า สูงสุด 10 หน้า) ไม่เปลี่ยนตำแหน่งอ่าน
- ต้นทางถูกลบ / ไม่มีสิทธิ์เห็น (เช่น สมาชิกใหม่กับข้อความก่อนเข้ากลุ่ม) → "ข้อความนี้ไม่พร้อมใช้งาน" ไม่ส่งข้อความ รูป หรือชื่อผู้ส่งมาให้
- ห้องร้านค้า: ลูกค้าเห็นผู้ส่งต้นทางเป็นชื่อร้าน (ไม่เผยชื่อส่วนตัวของเจ้าของร้าน)

## Reaction
- กดค้าง → 👍 ❤️ 😂 😮 😢 🙏 / 1 คน 1 Reaction ต่อข้อความ เปลี่ยน/ถอนได้ (แตะอีโมจิของเราใต้ข้อความ = ถอน)
- แสดงบนจอทันที ไม่สำเร็จ → คืนค่าเดิม + แจ้งเตือนบนจอ / ไม่นับยังไม่อ่าน ไม่ส่ง Push
- ข้อความที่โหลดไว้แล้ว (ล่าสุดไม่เกิน 100 ข้อความ) อัปเดต Reaction ทุกครั้งที่ดึงข้อความใหม่ (`states_from`)

## สถานะข้อความของเรา
- กำลังส่ง… / ส่งไม่สำเร็จ · แตะเพื่อส่งอีกครั้ง / ส่งแล้ว (= บันทึกบนเซิร์ฟเวอร์แล้ว)
- ส่วนตัว/ร้านค้า: "อ่านแล้ว" ตามตำแหน่งอ่านจริงของอีกฝ่าย
- กลุ่ม: "อ่านแล้ว X คน" นับเฉพาะสมาชิกรอบปัจจุบันที่เห็นข้อความนั้นได้ ไม่นับผู้ส่ง ไม่มีรายชื่อผู้อ่าน
- นับว่าอ่านเมื่อห้องอยู่ด้านหน้า แอปเปิดอยู่ และเห็นข้อความล่าสุดจริง (อยู่ล่างสุด) — หลายเครื่องไม่ถอยหลัง
- ไม่มีสถานะ "ถึงเครื่องแล้ว (delivered)"

## API
- `GET /chats/{id}/messages?mark_read=0&states_from=` / `POST /chats/{id}/read {message_id}`
- `PUT|DELETE /chats/{id}/messages/{m}/reaction` / `PUT|DELETE /group-chats/{id}/messages/{m}/reaction`
- ส่งข้อความ: `reply_to_id` (ห้องเดียวกันและมีสิทธิ์เห็น ไม่งั้น 422 `reply_unavailable`)
- แอปเวอร์ชันเก่าที่ไม่ส่ง `mark_read` ยังนับว่าอ่านตอนโหลดข้อความแบบเดิม

## ข้อจำกัด
- ดึงข้อความใหม่ทุก 4 วินาที (ไม่ใช่ realtime) เฉพาะตอนห้องอยู่ด้านหน้า
- แตะไปต้นทางที่เก่ากว่า 10 หน้า → แจ้ง "ไม่พบข้อความต้นทาง"
- Reaction ของข้อความเก่ากว่า 100 ข้อความล่าสุดที่โหลดไว้ อัปเดตเมื่อเปิดห้องใหม่
