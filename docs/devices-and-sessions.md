# อุปกรณ์ที่เข้าสู่ระบบ (เซสชัน)

หน้าแอป: **ตั้งค่า → บัญชี → อุปกรณ์ที่เข้าสู่ระบบ**

## เซสชันคืออะไร

- 1 เซสชัน = 1 Sanctum personal access token ชื่อ `family-app`
  - สร้างตอนสมัคร เข้าสู่ระบบด้วยรหัสผ่าน หรือ Social Login (`App\Support\AppSessions::issue`)
- token ชื่ออื่น (เช่น บัญชีบริการ) ไม่แสดงในรายการ และไม่ถูกเพิกถอนจากหน้านี้
- token หมดอายุ 30 วันหลังเข้าสู่ระบบ (`SANCTUM_TOKEN_EXPIRATION`) และไม่แสดงในรายการหลังหมดอายุ
- "เครื่องนี้" = token ของคำขอที่เรียกดูรายการ (ไม่เดาจากชื่อรุ่น)
- "ใช้งานล่าสุด" = `last_used_at` ที่ Sanctum บันทึกทุกครั้งที่เรียก API
  - ไม่มีสถานะ "ออนไลน์" เพราะ token ที่ยังไม่หมดอายุไม่ได้แปลว่าเครื่องเปิดอยู่

## ข้อมูลอุปกรณ์

- แอปส่ง `device_name`, `device_platform`, `os_version`, `app_version` ไปตอนเข้าสู่ระบบ
  - อ่านด้วย `device_info_plus` และ `package_info_plus`
  - ไม่อ่าน IMEI หมายเลขเครื่อง หรือชื่อเครื่องที่ผู้ใช้ตั้งเอง
- เซิร์ฟเวอร์ถือเป็นข้อมูลแสดงผลเท่านั้น
  - ตัดอักขระควบคุมและจำกัดความยาว
  - ค่าที่รูปแบบไม่ถูกจะไม่ถูกเก็บ แต่ไม่ทำให้เข้าสู่ระบบไม่สำเร็จ
  - ไม่ใช้ยืนยันตัวตน
- เซสชันเดิมก่อนมีฟีเจอร์นี้ไม่มีข้อมูล → แสดง "อุปกรณ์ไม่ทราบชื่อ"
  - เมื่อเครื่องนั้นเปิดแอปเวอร์ชันใหม่ แอปจะเรียก `PUT /api/sessions/current` เพื่อเติมชื่อของเซสชันตัวเอง
- migration เพิ่มคอลัมน์ว่างใน `personal_access_tokens` เท่านั้น: token เดิมใช้ได้ต่อ ไม่มีใครหลุดจากระบบ

## API (`throttle:sessions` 30 ครั้ง/นาที)

| Method | Path | ทำอะไร |
|---|---|---|
| GET | `/api/sessions` | รายการเซสชันของตัวเอง ไม่มี token หรือ hash |
| PUT | `/api/sessions/current` | เติมข้อมูลอุปกรณ์ของเซสชันนี้ |
| DELETE | `/api/sessions/{id}` | เพิกถอนเซสชันอื่น |
| POST | `/api/sessions/revoke-others` | เพิกถอนทุกเซสชันยกเว้นเครื่องนี้ |

`DELETE /api/sessions/{id}`:

- id ของคนอื่นหรือที่ยกเลิกไปแล้ว → ตอบ `revoked: 0` เหมือนกัน (ไม่บอกว่ามีอยู่ และไม่มีผลกับใคร)
- id ของเครื่องนี้ → 422 (ให้ใช้ปุ่มออกจากระบบเดิม)

**เพิกถอน = ลบ token จริง**

- เครื่องนั้นเรียก API ครั้งถัดไปได้ 401 แล้วแอปพากลับหน้าเข้าสู่ระบบ
- เครื่องที่ออฟไลน์อยู่จะออกจากระบบตอนต่อเน็ตครั้งถัดไป

## การผูกกับ Push

- `device_tokens.access_token_id` ผูกรหัส Push ของเครื่อง (Firebase FID) กับเซสชันที่ลงทะเบียน
- **เพิกถอนเซสชัน:** แถว Push ที่ผูกกับเซสชันนั้นถูกลบ
  - ลบเองใน `AppSessions::revoke` และ foreign key ลบตาม (cascade) อีกชั้น
  - เครื่องอื่นและบัญชีอื่นไม่ถูกแตะ
- **Push ที่ส่งถึงเครื่องไปแล้วเรียกคืนไม่ได้** ระบบหยุดได้เฉพาะการส่งครั้งต่อไป
- **รหัส Push ของเครื่องเปลี่ยน:** รหัสใหม่ผูกกับเซสชันเดิม และรหัสเก่าของเซสชันเดียวกันถูกลบ (1 เซสชัน = 1 เครื่อง)
- **เปลี่ยนบัญชีบนเครื่องเดียวกัน:** รหัสเครื่องย้ายไปเป็นของบัญชีใหม่และเซสชันใหม่ (เหมือนเดิม)
- **แถวเก่าที่ไม่มี `access_token_id`:** ไม่ถูกใช้ส่ง Push อยู่แล้ว (`DeviceToken::loggedIn`)
  - ไม่ลบแบบเดา: จะถูกผูกใหม่เมื่อเครื่องนั้นเปิดแอปด้วยเซสชันที่ใช้ได้
  - หรือถูกตัดออกเมื่อเกิน 10 เครื่องต่อบัญชี

## เมื่อได้ 401 ในแอป

- **หน้าแอป:** ลบ token แล้วไปหน้าเข้าสู่ระบบ (`ApiHelper.onUnauthorized`)
  - หน้าหลักถูกปิด จึงหยุดส่งตำแหน่งขณะเปิดแอป ปิดสวิตช์แชร์ตำแหน่งเบื้องหลัง และหยุด polling ของหน้าแชท/แผนที่
- **บริการส่งตำแหน่งเบื้องหลัง:** ได้ 401 → หยุดและปิดสวิตช์
  - ไม่เริ่มเองตอนเปิดเครื่อง และไม่ส่งคำขอที่ไม่มีสิทธิ์ต่อเนื่อง
