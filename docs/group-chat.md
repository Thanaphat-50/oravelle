# แชทกลุ่มครอบครัว

## โครงสร้าง

| ตาราง | หน้าที่ |
|---|---|
| `group_chats` | 1 กลุ่ม = 1 ห้อง (`family_id` ไม่ซ้ำ จึงเปิดพร้อมกันได้ห้องเดียว) ชื่อห้องอ่านจากชื่อกลุ่มทุกครั้ง |
| `group_chat_members` | สิทธิ์ของสมาชิก "หนึ่งรอบ" ผูกกับแถว `family_members` หนึ่งแถว (foreign key ลบตาม) |
| `group_chat_messages` | ข้อความ/รูป, `client_id` ไม่ซ้ำต่อห้อง + ผู้ส่ง |

- ตาราง `conversations` / `chat_messages` ของแชทส่วนตัวและแชทร้านค้าไม่ถูกแตะ
- ระบบสมาชิกกลุ่มเดิมเป็นแหล่งสิทธิ์เดียว ไม่มีรายชื่อสมาชิกแชทแยกอีกชุด

## ขอบเขตข้อความย้อนหลัง

- **เข้ากลุ่ม** (สร้างกลุ่ม / รหัสเชิญ / คำเชิญ / อนุมัติคำขอ):
  - `visible_after_id` = id ของข้อความล่าสุดในห้องตอนเข้า
  - เห็นเฉพาะข้อความที่ id มากกว่านั้น ใช้ id ไม่ใช้เวลา จึงไม่มีข้อความก่อนเข้าหลุดมา
- **ออก / ถูกนำออก:** แถว `family_members` ถูกลบ สิทธิ์ของรอบนั้นจึงหายตาม
  - อ่าน ส่ง โหลดเพิ่ม ข้อความเดียว รูปแนบ ยังไม่อ่าน และเปิดจากแจ้งเตือน ใช้ไม่ได้ทันที
- **กลับเข้าใหม่:** เป็นแถวใหม่ เห็นเฉพาะข้อความหลังเข้ารอบใหม่ ไม่คืนประวัติรอบเก่า
- **โอนเจ้าของ:** แถวสมาชิกเดิมยังอยู่ ประวัติไม่เปลี่ยน
- **กลุ่มและสมาชิกเดิมก่อนมีฟีเจอร์นี้:**
  - ห้องถูกสร้างตอนมีคนเปิดครั้งแรก และสมาชิกปัจจุบันทุกคนเห็นตั้งแต่ข้อความแรกของห้อง (ซึ่งยังว่าง)
  - ไม่ดึงแชทส่วนตัวเก่ามารวม
- **ลบกลุ่ม:** ห้อง ข้อความ และสิทธิ์ถูกลบตาม (cascade) ใช้ห้องไม่ได้ทันที และไฟล์รูปถูกลบหลังลบข้อมูลสำเร็จ (เหมือนโพสต์ของกลุ่ม)
- **ลบบัญชี:**
  - ข้อความและรูปของบัญชีนั้นถูกลบ
  - ถ้าเป็นเจ้าของกลุ่มคนเดียว กลุ่มและห้องทั้งห้องถูกลบ
- **ส่งพร้อมกับถูกนำออก:**
  - การส่งล็อกแถวสมาชิกในธุรกรรมเดียวกับการบันทึกข้อความ
  - ถ้าการนำออกเกิดก่อน ข้อความจะไม่ถูกรับ

## รูปแนบ

- ตรวจชนิด (JPG/PNG/WEBP) และขนาด (ไม่เกิน 4 MB) ที่เซิร์ฟเวอร์
- จำกัดการส่ง: ข้อความ 30 ครั้ง/นาที, รูป 10 รูป/นาที และ 60 รูป/ชั่วโมงต่อคน
- เก็บใน disk ส่วนตัว (Cloud = Private Bucket, ในเครื่อง = `local`) ไม่มี URL สาธารณะ
- แอปได้ลิงก์ลงลายเซ็นอายุ 10 นาทีที่ผูกกับผู้ดู
  - ทุกครั้งที่เปิดลิงก์ เซิร์ฟเวอร์ตรวจสิทธิ์ของผู้ดูอีกรอบ หมดสิทธิ์แล้วเปิดไม่ได้แม้ลิงก์ยังไม่หมดอายุ
  - **ข้อจำกัด:** ถ้าลิงก์หลุดไปถึงคนอื่น คนนั้นเปิดได้จนกว่าลิงก์จะหมดอายุ และเจ้าของลิงก์ยังมีสิทธิ์อยู่
- ลิงก์หมดอายุระหว่างเปิดห้องนาน ๆ → แอปให้แตะเพื่อขอลิงก์ใหม่
- **หมดสิทธิ์:** แอปล้างข้อความและรูปที่แสดงในหน่วยความจำของห้องนั้น
  - รูปที่ผู้ใช้บันทึกหรือดาวน์โหลดไว้ก่อนหน้า ระบบเรียกคืนไม่ได้
- ข้อมูลผู้ส่งมีแค่ id ชื่อ รูปโปรไฟล์ (ไม่มีอีเมลหรือเบอร์โทร)

## ยังไม่อ่าน

- `last_read_id` แยกต่อสมาชิก และไม่ถอยหลัง (อีกเครื่องอ่านไปไกลกว่าแล้วไม่ถูกดึงกลับ)
- นับเฉพาะข้อความของคนอื่นที่เห็นได้
- เปิดรายการแชทเฉย ๆ ไม่นับว่าอ่าน: อ่านเมื่ออยู่ในห้องและเห็นข้อความล่าสุด
- ยอดบนไอคอนแชท = แชทส่วนตัว + แชทกลุ่ม (`/api/chats/unread-count`)

## แจ้งเตือน

- **ผู้รับ:** สมาชิกปัจจุบันที่เห็นข้อความนั้น
  - ไม่แจ้งผู้ส่ง คนที่ปิดเสียงห้อง คนที่บล็อกผู้ส่ง และคนที่ปิด "ข้อความแชท" ในตั้งค่า
- **ตรวจสิทธิ์ใหม่ตอนส่งจริง:** Push ส่งหลังตอบแอปแล้ว (defer)
- **ข้อความทั่วไป:** "แชทกลุ่ม / มีข้อความใหม่ในกลุ่ม" ไม่มีเนื้อหาหรือชื่อกลุ่มบนหน้าจอล็อก
- **การส่ง:**
  - ส่งไปทุกเครื่องที่ยังเข้าสู่ระบบอยู่ (เซสชันที่ถูกยกเลิกไม่ได้รับ)
  - ไม่สร้างรายการในหน้าแจ้งเตือน (เหมือนแชทส่วนตัว)
- **กติกาการบล็อกในห้องกลุ่ม (ผู้ใช้เลือก):** การบล็อกไม่ไล่ใครออกและไม่ห้ามส่ง
  - ข้อความยังเห็นและนับยังไม่อ่านตามปกติ
  - ผู้บล็อกแค่ไม่ได้รับ Push จากข้อความของคนที่ตนบล็อก

## รับข้อความใหม่

- ใช้ polling เดิมทุก 4 วินาที
- ดึงเฉพาะตอนหน้าห้องอยู่ด้านหน้าและแอปเปิดอยู่ ไม่ยิงซ้อน และโหลดเฉพาะข้อความหลัง id ล่าสุด
- ไม่ใช้บริการภายนอกเพิ่ม และไม่ต้องตั้งค่า Cloud เพิ่ม
